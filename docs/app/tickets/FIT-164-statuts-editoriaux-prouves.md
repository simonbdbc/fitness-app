# FIT-164 — Statuts éditoriaux prouvés

Statut : `IN_PROGRESS` · EPIC-031.

Remplacer les statuts générés automatiquement par des décisions traçables ;
reclasser immédiatement les placeholders/incomplets hors programmation.

Preuve intermédiaire du 12 août 2026 : les 707 fiches V2 complètes sont
`translated` mais restent 703 `a_verifier`, 4 `a_revoir` et toutes
`library_only`. Les 555 fiches incomplètes sont exclues par le contrat V2 ; la
revue humaine reste requise avant toute remontée de statut.
