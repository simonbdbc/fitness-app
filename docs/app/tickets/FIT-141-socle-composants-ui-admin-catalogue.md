# FIT-141 - Socle composants UI admin catalogue

## Statut

`IN_PROGRESS` — implémenté localement, requalification V1 en cours.

## Objectif

Extraire les composants communs depuis la page canonique
`/admin/catalogue/intervalles`.

## Criteres d'acceptation

- Le socle contient page, header, messages, stats, toolbar, liste, carte,
  liste CRUD standard, modal et actions formulaire.
- La page `intervalles` conserve sa structure visuelle et fonctionnelle.
- Les nouvelles pages reutilisent les composants extraits.
- Le socle inclut la multi-selection par badges et le disclosure `Formats liés`.
