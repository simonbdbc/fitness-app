# FIT-138 - Route Admin Equipements

## Statut

`IN_PROGRESS` — validation locale acquise, requalification V1 en cours.

## Objectif

Ajouter une entree admin locale pour gerer les equipements du catalogue.

## Taches

- Ajouter la vue `adminCatalogEquipment` dans le mapping de navigation.
- Ajouter la route Expo `/admin/catalogue/equipements`.
- Ajouter l'entree `Equipements` dans le menu Admin.
- Exporter l'ecran depuis le module catalogue.

## Criteres d'acceptation

- La route `/admin/catalogue/equipements` affiche l'ecran CRUD.
- Le menu Admin expose l'entree `Equipements`.
- Le mapping de pathname active la bonne entree de navigation.
